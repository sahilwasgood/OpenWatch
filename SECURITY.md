# Security policy

OpenWatch is local-first: no account, no server, no telemetry. Watch and health data never leave
the device unless you explicitly enable the optional AI interpretation layer and approve the
payload shown before it is sent.

## Reporting a vulnerability

Open an issue in this repository with reproduction steps and the affected platforms. If the
report contains sensitive detail, ask the maintainer for a private channel first. Reports are
acknowledged within a week and fixes are prioritized by impact.

## Supported versions

Only the latest commit on the default branch receives fixes.
